# Design Risks and Trade-offs

| # | Risk | Impact | Mitigation | MVP approach | Production approach |
|---|---|---|---|---|---|
| 1 | **LLM hallucination** (invented categories, indicators, facts) | False risk signal; wrong escalation | Evidence-first verification; indicators need verified quotes; unknown category → invalid response; AI never scores | Existing verifier + D-19 fix; analyst reviews every factor | Add typology/indicator topic cues for all high-impact indicators; periodic faithfulness evals |
| 2 | **Inconsistent AI output** across runs | Different factors for same input | Low temperature (0.1); pinned model; JSON schema; carried-forward ratings flagged; consistency metric in evals | Pin model; `EVAL_RUNS=3` consistency check on 5 cases | Scheduled consistency evals; alert on drift |
| 3 | **Incorrect / off-topic evidence** (quote exists but does not support the indicator — seen in eval RA-005) | Spurious CRITICAL via sanctions rule | Topic-cue check (exists for sanctions); rule fires only on accepted indicator; analyst can exclude; challenge findings | Keep sanctions cues; add cues before approving new indicators | Lightweight entailment check (second model) as *advisory* flag, never as gate |
| 4 | **Non-reproducible scoring** | Audit failure | Pure engine, snapshots, engine version, inputs hash, replay test | Add engine version + replay test | Integrity job re-verifies all current calcs nightly |
| 5 | **Prompt changes** alter behaviour silently | Unexplained result shifts | Prompt registry; startup fails on changed template without version bump; eval gate | Registry + gate | Prompt diff review in PR template; baseline per version |
| 6 | **Model changes** (provider swaps model behind alias) | Drift; quality drop | Pin exact model id; record `response_model`; allow-list | Pin + record | Alert when `response_model ≠ requested_model` |
| 7 | **Incomplete assessment data** | Low-quality analysis, wasted LLM spend | `validate_input` gate; missing-information lists; info-request flow; confidence LOW | Gate + confidence | Configurable completeness rules per change type |
| 8 | **Schema evolution** on a live Neon DB | Downtime / data loss | Expand→migrate→contract; Neon branch rehearsal; PITR rollback | Migrations 0009–0014 additive | DB-level constraints, JSONB/timestamptz conversions in maintenance windows |
| 9 | **Long-running AI workflows** (up to 120 s per call) | Request timeouts, blocked event loop, lost work on restart | Async job + polling; per-node progress; job recovery on startup; no DB transaction across LLM call | In-process pool, single instance | Dedicated worker with `SKIP LOCKED` queue; LangGraph checkpointing if runs lengthen |
| 10 | **API failures** (OpenRouter 429/5xx/timeouts) | Analysis unavailable | Retry with back-off; typed errors; rules-only fallback; unavailable mode never overwrites | Existing degraded mode | Circuit breaker; secondary model route via gateway config |
| 11 | **External model availability / data residency** | Blocked processing; compliance issue | Gateway abstraction; masking; zero-retention providers | OpenRouter + masking | Enterprise-hosted endpoint option; DPA with provider (Q-06) |
| 12 | **Human override governance** (risk lowered without justification) | Under-assessed risk approved | Reason ≥ 20 chars; floor protection; downward override → HIGH finding needing manager acceptance; audit before/after | Implement rules in Stage 3 | Override analytics in governance report; periodic QA sampling |
| 13 | **Access-control gaps** (D-01, D-02, D-05) | Data exposure; unauthorised methodology change | Permission matrix; table-driven tests | P0 fixes | Gateway WAF + SSO; quarterly access review |
| 14 | **Neon idle suspend / pooler semantics** | Stale connections; cold-start latency; broken advisory lock via pooler | `pool_pre_ping`, `pool_recycle`; direct URL for migrations; connect timeout | Configure | Disable autosuspend on prod; monitor p95 latency |
| 15 | **Scope creep into generic financial risk** (OCC credit/liquidity lens) | Confused product, wrong risk model | Remove OCC panel from UI; FC-only categories and typologies | Hide panel | Keep FC scope in methodology governance |
| 16 | **Monolith growth** (5k-line router, 8.5k-line component) | Slow delivery, regressions | Split by capability; layering rules | Split the two largest files | Enforce module boundaries with import-linter |
| 17 | **Evaluation gate currently failing** | Cannot demonstrate AI quality | Pin capable model; re-baseline; expand dataset | Required before demo | Continuous evals in CI (weekly workflow exists) |
| 18 | **Single-instance MVP** (in-process jobs + loops) | No HA; scaling blocked | Documented limit; stateless API otherwise | Accept for hackathon | Split worker; platform scheduler |
